# Design System Extraction Example

This example demonstrates how an agent can extract a unified design system (colors, fonts, etc.) from multiple screens generated by the Stitch SDK.

It represents a **Tier 2 Agent Skill**. Generating a design system requires agent intelligence to not only extract configurations but also logically reconcile conflicts across them (e.g., merging differing hex values for a "primary" color).

## Contents

- `SKILL.md`: Instructions for an AI agent on how to extract and reconcile design tokens from multiple Stitch SDK screens.
- `scripts/extract-tokens.ts`: A helper script demonstrating how to programmatically generate screens, fetch their HTML, and extract their Tailwind config and Google Fonts links.

## Prerequisites

- Set the `STITCH_API_KEY` environment variable.

## Running the Script

You can run the extraction helper script to see how it pulls and compares configurations from multiple screens:

```bash
bun packages/sdk/examples/design-system-extraction/scripts/extract-tokens.ts
```

*Note: Generating screens takes time. The script will output its progress and the final reconciliation analysis.*
