# Agent Skill: Build a Vite Preview App from a Design

You are an expert frontend engineer. Your task is to take a Stitch SDK generated UI design screen and scaffold a live-previewable **Vite + React + Tailwind v4** application from it.

Stitch screens return HTML with an embedded JSON `tailwind.config` block (designed for Tailwind v3 CDN). However, modern Vite applications use Tailwind v4, which defines themes using the CSS `@theme` directive in the main stylesheet.

Follow these steps to seamlessly integrate a design into Vite.

## Step 1: Extract the Design Artifacts

1. Fetch the screen's HTML using the Stitch SDK.
2. Use the provided utility script to extract the Tailwind v4 `@theme` block from the embedded v3 JSON config:
   ```bash
   bun packages/sdk/examples/vite-preview/scripts/extract-theme.ts <SCREEN_ID> > theme.css
   ```
3. Read the `theme.css` file to see the extracted colors, fonts, and other tokens.

## Step 2: Scaffold the Vite App

Initialize a new Vite React app in the target directory (e.g., `preview-app`):

```bash
npm create vite@latest preview-app -- --template react-ts
cd preview-app
```

Install Tailwind v4 and its Vite plugin:

```bash
npm install tailwindcss @tailwindcss/vite
```

Update `vite.config.ts` to include the Tailwind plugin:

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    tailwindcss(),
    react()
  ],
})
```

## Step 3: Integrate the Theme

Replace the contents of `src/index.css` with the extracted Tailwind v4 configuration:

```css
@import "tailwindcss";

/* Extracted from Stitch Design Token Config */
@theme {
  --color-primary-50: #eff6ff;
  /* ... inject the contents generated by the extract-theme.ts script ... */
}
```

## Step 4: Include Google Fonts

Stitch designs often rely on Google Fonts. Look for `<link href="...fonts.googleapis.com...">` tags in the original Stitch HTML `<head>`.

Copy those font `<link>` tags into the `<head>` of `index.html` in the Vite project. Also, be sure to update any absolute asset paths referenced in the HTML to point appropriately (or leave them as absolute CDN links if they are `lh3.googleusercontent.com` images).

## Step 5: Convert HTML to JSX

Extract the `<body>` content from the Stitch HTML and convert it to React JSX. Place this in `src/App.tsx`.

**Critical conversions:**
- `class=` -> `className=`
- `for=` -> `htmlFor=`
- Ensure self-closing tags like `<img>` and `<input>` are properly closed (e.g., `<img />`).
- Remove any inline `style=` strings and replace with React style objects or extract to Tailwind classes if possible.

## Step 6: Test the App

Run the development server to verify the output:

```bash
npm run dev
```

Verify that custom colors, custom fonts, and layouts match the original Stitch design screenshot.
