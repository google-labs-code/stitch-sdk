# Next.js Integration Example

This example demonstrates how to integrate the HTML and Tailwind assets generated by `@google/stitch-sdk` into a Next.js App Router application.

It acts as an **Agent Skill**, providing a `SKILL.md` file with instructions for an AI agent and a helper script to automate the heavy lifting of extracting and converting the code.

## Requirements

*   Bun, npm, or another Node.js package manager
*   `STITCH_API_KEY` set in your environment

## Structure

*   **`SKILL.md`:** Instructions intended for an AI Agent explaining how to process Stitch SDK output for Next.js.
*   **`scripts/scaffold-nextjs.ts`:** A helper script that automates the downloading of a screen, extraction of the Tailwind configuration and Google Fonts, and the initial conversion of HTML to JSX within a basic Next.js scaffolding.

## Running the Helper Script

The helper script can be run directly from the command line to scaffold a Next.js project based on either a text prompt or an existing Project/Screen ID.

### Option 1: Generate a new design from a prompt

```bash
bun scripts/scaffold-nextjs.ts --prompt "A modern dark mode landing page for a SaaS product with a hero section and features grid" --outDir ./my-next-app
```

### Option 2: Use an existing project and screen

If you already have a design generated in Stitch, provide the IDs:

```bash
bun scripts/scaffold-nextjs.ts --projectId "YOUR_PROJECT_ID" --screenId "YOUR_SCREEN_ID" --outDir ./my-next-app
```

## What the script does

1.  Fetches the raw HTML for the specified design.
2.  Extracts the `<script id="tailwind-config">` block and creates a `tailwind.config.ts`.
3.  Extracts Google Fonts `<link>` tags and injects them into `app/layout.tsx`.
4.  Performs a basic conversion of the HTML `<body>` into JSX (e.g., changing `class` to `className`) and places it in `app/page.tsx`.
5.  Sets up a `next.config.js` to allow images from Google's and Unsplash's CDNs.

## Post-Scaffolding Steps

After running the script, you'll need to install dependencies and start the dev server in the generated output directory:

```bash
cd my-next-app
npm init -y
npm install next react react-dom tailwindcss postcss autoprefixer
npx tailwindcss init -p
npx next dev
```
